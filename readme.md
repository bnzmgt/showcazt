# Showcazt

A simple plugin for managing affiliate products. Create categories, add products, and display them individually or on specific pages using shortcodes.

## Authors

-   [Distrapps](https://distrapps.com/)

## Features

-   Affiliate Product Management (Admin)
-   Custom Database Tables
-   Product Categories (Internal Grouping)
-   Multiple Product Images (Swiper Slider)
-   Shortcode Display (Post, Page, Template)
-   Link Wrapper & Redirect System (/go/{slug})
-   Click Tracking (Server-side)
-   Enable / Disable Product (Soft Off)
-   Fallback Redirect Handling
-   Admin Click Statistics
-   SEO-Safe (No Single Page & Noindex Archive)

## Setup

-   Upload the plugin folder to your /wp-content/plugins/ folder.
-   Go to the **Plugins** page and activate the plugin.
